# أداة الإرسال الجماعي (APK مستقل)

تطبيق أندرويد **بدون سيرفر**. بعد التفعيل تظهر **أيقونة منبثقة**؛ الضغط عليها يفتح نموذج الإرسال.

## الاستخدام
1. افتح التطبيق وفعّل:
   - خدمة الوصول
   - الظهور فوق التطبيقات
2. اضغط **تشغيل الأيقونة المنبثقة** (يغلق التطبيق ويبقى الفقاعة فقط)
3. اضغط الأيقونة العائمة → نموذج:
   - لصق الرسائل
   - شريط الرسائل/دقيقة (حتى 1000)
   - زر إرسال فقط
4. ادخل محادثة واتساب
5. عند انتهاء كل الرسائل تظهر **رسالة نجاح** في نفس النموذج

## بناء APK
```bash
export ANDROID_HOME=$HOME/android-sdk
cd android-app
./gradlew assembleDebug
```

نسخة جاهزة: `releases/bulk-sender.apk`
