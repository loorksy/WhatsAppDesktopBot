# تطبيق الإرسال الجماعي (APK)

تطبيق أندرويد أصلي للإرسال الجماعي عبر سيرفر واتساب بوت.

## الشاشات
1. تسجيل الدخول + رابط السيرفر
2. قائمة المحادثات (يجب الدخول لمحادثة)
3. نموذج الإرسال: لصق الرسائل، عدد الرسائل/دقيقة، إرسال

## بناء APK
```bash
export ANDROID_HOME=$HOME/android-sdk
cd android-app
./gradlew assembleDebug
```

الملف الناتج:
`app/build/outputs/apk/debug/app-debug.apk`

## الاستخدام
1. ثبّت الـ APK على الجوال
2. أدخل رابط السيرفر (مثال: `http://YOUR_VPS_IP:3000`)
3. سجّل الدخول بحساب لديه صلاحية `can_send_messages`
4. ادخل محادثة ثم الصق الرسائل وأرسل
