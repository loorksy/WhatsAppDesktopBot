# أداة الإرسال الجماعي (APK مستقل)

تطبيق أندرويد **بدون أي سيرفر**. يعمل محليًا على الجوال ويرسل الرسائل داخل محادثة واتساب المفتوحة عبر خدمة إمكانية الوصول (Accessibility).

## التدفق
1. افتح التطبيق → قائمة الأدوات
2. اضغط **الإرسال الجماعي**
3. فعّل خدمة الوصول للتطبيق
4. الصق الرسائل واختر عدد الرسائل في الدقيقة
5. اضغط **إرسال** ثم ادخل إلى المحادثة في واتساب
6. يبدأ الإرسال تلقائيًا طالما أنت داخل المحادثة

## بناء APK
```bash
export ANDROID_HOME=$HOME/android-sdk
cd android-app
./gradlew assembleDebug
```

الملف:
`app/build/outputs/apk/debug/app-debug.apk`

## ملاحظات
- لا يتصل التطبيق بأي سيرفر أو إنترنت.
- يجب فتح محادثة واتساب (أو واتساب أعمال) حتى يظهر حقل الكتابة.
- أوقف الإرسال من التطبيق أو من الإشعار في أي وقت.
